Features

IFC file loading

Drag and drop IFC files into the viewer or use the file picker. Parsed with the web-ifc library.

3D visualization

Interactive 3D rendering of BIM models with Three.js. Zoom, pan, and rotate around the model.

Build sequence animation

Visualize the construction sequence step by step with play, pause, previous, and next controls. Choose which IFC parameter drives the sequence order.

Element properties

Click on any element to select and highlight it. View all IFC properties of the selected element.

Tech stack

Three.js

3D rendering engine for interactive model visualization.

web-ifc

IFC parsing library by IFCjs for reading Industry Foundation Classes files.

Vanilla JavaScript

No framework dependencies. Lightweight and fast.
