Features

BENG calculations

Building Energy Performance (BENG) calculations following the Dutch NTA 8800 standard with BENG indicator visualization.

U-value calculator

Calculate thermal transmittance (U-value) of wall, roof, and floor constructions.

Heat pump sizing

Calculate required heat pump capacity based on building properties and climate data.

Thermal bridge calculator

Assess thermal bridges and their impact on energy performance.

Energy breakdown charts

Visual energy breakdown and monthly performance analysis charts.

3D building view

3D visualization of the building envelope and its thermal properties.

Project management

Project browser for managing multiple buildings. Properties panel for detailed parameter editing.

Reporting

Generate energy performance reports with print preview. Ribbon toolbar interface with settings dialog.

Tech stack

Tauri 2

Native desktop application with Rust backend. CalVer versioning (YEAR.MONTH.BUILD).

React 18 + TypeScript

Component-based UI with Vite build tooling.
