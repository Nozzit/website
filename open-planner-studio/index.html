Features

Gantt charts

Interactive Canvas-rendered Gantt diagrams with drag and drop, zoom, and timeline navigation.

Critical Path Method

Automatic CPM calculation with critical path identification and float analysis.

Work Breakdown Structure

Hierarchical task structure with collapsible chapters. Excel-style table editor with inline editing.

IFC 4.3 native

Save and open planning files in IFC 4.3 format (buildingSMART standard). Built-in IFC code editor with generate and apply.

Resource management

Manage labor, equipment, and subcontractors. Construction-specific features: holidays, building recess, inspection moments, and phasing.

4D BIM-ready

Link planning tasks to IFC building model elements for 4D construction sequence visualization.

Reporting

Live print preview in the ribbon with configurable report options. Context menu for quick task actions.

Multilingual

Interface in 6 languages: Nederlands, English, Francais, Deutsch, Espanol, and Zhongwen.

Ribbon toolbar

Microsoft Office-style ribbon with tabs: Start, Planning, View, Settings, Table, IFC, and Report.

Tech stack

Tauri 2.0

Native desktop application with Rust backend.

React 18 + TypeScript

Component-based UI with Zustand + Immer state management.

HTML5 Canvas 2D

Gantt chart rendering. TailwindCSS styling, Vite 5 build.
