Extension for Open 2D Studio

Drawing Statistics

Extension that displays shape counts and drawing statistics. Adds an Add-Ins ribbon tab with a Shape Count button and a terminal command.

Download v1.0.1 (1.4 KB) View source

Features

Add-Ins ribbon tab

Adds a Shape Count button to the Add-Ins ribbon tab in Open 2D Studio.

Terminal command

Registers a stats show terminal command to display statistics from the command line.

Entity counting

Counts all entities by type in the current drawing.

Requires Open 2D Studio v0.15.0 or later.
