## Key features

- Gantt chart editing with dependencies
- WBS and task hierarchies
- Resource and calendar assignments
- 4D linkage to IFCX models
- Critical path visualisation

## Tech stack

`Rust` · `TypeScript` · `Tauri 2`

## When to use this

Construction project scheduling with optional 4D linkage to BIM models.
