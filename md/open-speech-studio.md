## Key features

- Local Whisper-based transcription
- OS-wide CTRL+Win dictation hotkey
- No cloud, no telemetry
- Multi-language support
- Configurable models (tiny / base / small / medium / large)

## Tech stack

`Rust` · `Whisper` · `Tauri 2`

## When to use this

Hands-free site notes, dictation for inspection reports, confidential dictation that may not leave the device.

- Dragon NaturallySpeaking
- Windows Speech Recognition
- macOS Dictation
