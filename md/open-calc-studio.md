## Key features

- Hierarchical cost build-up (chapters, sections, items)
- STABU and RAW catalog support
- IFCX integration for quantity take-off
- PDF and spreadsheet export
- MCP server for AI-driven estimation
- Multi-project workspaces

## Tech stack

`TypeScript` · `Rust` · `Tauri 2` · `MCP`

## When to use this

Building or civil project cost estimating using Dutch STABU/RAW catalogs, automated quantity take-off from IFCX models, AI-assisted estimating workflows.

## Alternative to

- Bouwprijs

## Standards & integration

- STABU
- RAW
- IFCX

All OpenAEC tools exchange data via the open **IFCX** format (based on IFC 4.3).
