Wat is Open CAD Studio?

Open CAD Studio is een experimenteel 2D CAD-framework dat dient als technologische basis voor de volgende generatie open-source CAD-tools binnen het OpenAEC-ecosysteem. Waar Open 2D Studio een complete toolchain levert, fungeert Open CAD Studio als een leerframework en architectuur-platform: hoe ziet een open, modulaire en performante CAD-engine eruit?

  • Lichtgewicht rendering — canvas-gebaseerde 2D-engine, snel zelfs bij grote tekeningen
  • Command-systeem — CAD-stijl commando-invoer met undo/redo en macro's
  • Plugin-architectuur — uitbreidbaar via add-ins voor specifieke domeinen
  • DXF / SVG interoperabiliteit — leesbaar tussen Open CAD Studio en de bredere CAD-wereld
  • Open source onderzoek — een speeltuin voor patronen die later in Open 2D Studio terechtkomen

Waarom een apart framework?

Open 2D Studio is een productie-CAD-applicatie. Daar willen we stabiliteit, niet experimenten. Open CAD Studio biedt de ruimte om radicaal andere architectuur-keuzes te onderzoeken — andere rendering-strategieën, andere data-modellen, andere interactiepatronen — zonder de productie-tool te destabiliseren.

Wat hier blijkt te werken, migreert door naar Open 2D Studio. Wat niet werkt, leren we van zonder gebruikers te raken.

Onderzoeksgebieden

Rendering-engine

Canvas 2D als baseline, met een viewport en transformatie-stack die schaalt naar honderdduizenden entiteiten. WebGPU-experiment voor de hot-loop in onderzoek.

Commandostructuur

CAD-style commands met argumenten, opties en preview-staat. Undo/redo via een journal van inverse commands.

Plugin-API

Add-ins kunnen commands registreren, ribbon-tabs toevoegen, en eigen entity-types definiëren. TypeScript-gedreven contract met run-time validatie.

Snapping & constraints

Object-snap (endpoint, midpoint, intersection) plus parametrische constraints — distance, parallel, perpendicular — als research-area.

Datamodel

Immutable entity tree met structural sharing. Tijd-reizen voor sessies en collaborative editing als toekomstig doel.

DXF / SVG I/O

DXF lezen en schrijven via een Rust-backend. SVG-export voor presentatie en web-embedding.

Technologie

TypeScript Tauri 2 Rust Canvas 2D WebGPU (experiment) Vite

Dezelfde grond-stack als alle OpenAEC-tools: TypeScript voor de UI, Rust voor de prestatie-kritieke paden, Tauri 2 voor cross-platform desktop-distributie (Windows, macOS, Linux).
